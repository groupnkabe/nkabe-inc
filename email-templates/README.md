# Nkabe Inc email templates

Static HTML templates for institutional outreach. Logo image uses the existing public website asset: `https://nkabe.us/assets/nkabe-inc-mark.webp`.

- `01-institutional-introduction.html` — first outreach
- `02-follow-up.html` — follow-up
- `03-thank-you.html` — post-conversation / next steps

Replace bracketed placeholders before sending. These templates are not configured as automated sending templates. Signature setup is intentionally deferred.

- Existing favicon: https://nkabe.us/assets/favicon-32.png
